# Product Brief

## 한 줄 정의

ArgusVene는 `사람 + AI 에이전트`가 함께 들어와 실시간으로 대화하고, 바로 산출물을 만들고, 그 결과를 결정과 실행으로 연결하는 `라이브 회의실 중심 운영 시스템`이다.

## 절대 바뀌지 않는 제품 조건

### 1. 회의실이 본체다

- 제품 중심은 `Meeting Room`
- 다른 페이지는 회의실을 준비하거나, 회의 결과를 이어받기 위한 보조 레이어다

### 2. 3패널 구조는 유지한다

- 왼쪽: 인간 대화, 라이브 트랜스크립트, 직접 지시
- 가운데: Live Canvas, 생성물, 실행 결과, 검토 대상
- 오른쪽: 참여자, 에이전트, 룸 운영, 역할 제어

### 3. 다중 사용자여야 한다

- 여러 사용자가 동시에 같은 미팅룸에 들어와야 한다
- 누가 말했는지 식별돼야 한다
- 사람 초대, 제거, 권한 변경이 가능해야 한다

### 4. 에이전트는 수동 응답기가 아니다

- 에이전트는 실제 역할을 가진 참여자처럼 보여야 한다
- 직접 개입하고, 반론하고, 작업을 제안하고, 결과물을 만든다
- 가운데 Live Canvas에 영향을 주는 행동이 가능해야 한다

### 5. 회의는 끝이 아니라 시작이다

- 회의 결과는 요약으로 끝나지 않는다
- `artifact`, `decision`, `task`로 이어져야 한다

### 6. make -> review -> revise 루프가 있어야 한다

- 회의 중 바로 만든다
- 바로 본다
- 바로 수정 지시를 내린다
- 다시 만든다

## 현재 제출용 최소 제품

오늘 기준으로 반드시 살아 있어야 하는 흐름:

1. 로그인
2. 워크스페이스 진입
3. 사람과 에이전트를 포함해 룸 개설
4. 라이브 미팅룸 입장
5. 텍스트와 음성으로 상호작용
6. 에이전트가 가운데 캔버스에 결과물 생성
7. 결과물 검토 후 다시 수정 지시
8. 결정과 태스크 저장

## 제외 대상

- 데모용 가짜 버튼
- 연결 예정 패널
- 기능 없는 화려한 UI
- 중복 화면 실험본
