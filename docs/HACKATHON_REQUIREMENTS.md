# Hackathon Requirements

기준 출처:

- Gemini Live Agent Challenge overview
- Gemini Live Agent Challenge rules

## 제출 관점에서 반드시 만족해야 하는 것

### 1. Gemini를 실제로 사용해야 한다

- 단순 이름만 쓰는 것이 아니라 실제 모델 호출이어야 한다
- Google Gen AI SDK 또는 ADK 경로를 사용해야 한다

### 2. Google Cloud 위에서 동작해야 한다

- 백엔드가 Google Cloud에서 돌아가야 한다
- 제출 시 이를 설명할 수 있어야 한다

### 3. Live Agents 성격이 보여야 한다

- 실시간 상호작용
- 자연스러운 대화
- Audio/Vision 중심의 live interaction

### 4. simple text in / text out를 넘어서야 한다

- 음성 상호작용이 핵심이다
- 가능하면 시각적 라이브 캔버스도 같이 보여야 한다

### 5. 공개 코드 저장소가 필요하다

- 현재 기준 저장소는 GitHub에 공개되어 있어야 한다

### 6. 제출 패키지가 필요하다

- README
- 아키텍처 설명
- 데모 영상

## 한국 시간 기준 마감

## 현재 제품에 바로 반영해야 하는 요구사항

- 라이브 음성 상호작용
- 실제 멀티유저 룸
- 실시간 에이전트 개입
- 실제 작동하는 캔버스 결과물
- Google Cloud 배포 가능 구조
